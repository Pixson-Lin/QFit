QFit User Guide

First-run walkthrough

No sign-in. On-device permissions only. Nothing uploaded to the developer.

Follow the order of a first launch: install, finish the required settings, then complete your first run.

0. Before you start

  • An Android phone (Android 12 or newer recommended)
  • Health Connect installed (built in on many phones; otherwise get it from Play Store)
  • The QFit install file (APK)
Please note: QFit writes simulated steps for personal testing and entertainment only. Follow the terms of any health or game app you use. Use at your own risk.

1. Install and open QFit

  1. Copy the APK to your phone and tap to install.
  2. If Android blocks unknown sources, allow installs from that source, then try again.
  3. Open QFit. On Home you can set type and duration, use the four checkboxes in a 2×2 grid below, and open History at the bottom right.

2. Allow Health Connect write access

On first launch, Android usually shows the Health Connect permission screen automatically. Allow QFit to write steps, distance, and exercise.

  1. Allow the required items (you can use Allow all), then tap Allow.
  2. Back on Home, confirm Health Connect is checked.
  3. If the prompt did not appear, or you denied it earlier: tap Health Connect on Home and grant access again.
Tip: QFit does not need a Google sign-in and never sends your account to the developer. Data stays in Health Connect on this phone for other apps to read.

3. Turn on Run notification

Run notification on Home is on by default—keep it on. While a run is active, an ongoing notice appears so the system is less likely to kill the app.

  1. Confirm Run notification is checked.
  2. If Android asks for notification permission, choose Allow (common on Android 13+).
If you turn Run notification off, there is no ongoing notice and the app is easier to kill when the screen is off. Step writes may be less reliable. Keep it on for normal use.

4. Set Battery Optimization to Unrestricted

This step matters. With Unrestricted, QFit can keep writing steps to Health Connect while the screen is off.

  1. Tap Battery Optimization on Home.
  2. A guide dialog appears: App info → Battery → Unrestricted.
  3. Tap Open settings.
  4. On QFit’s App info page, tap App battery usage (some phones show Battery).
  5. Choose Unrestricted (wording may vary by OEM).
  6. Return to QFit and confirm Battery Optimization is checked.
Menu names differ by brand; the goal is always Unrestricted battery usage for QFit. If the checkbox does not update immediately, check again on Home.

5. Simulate activity & distance (optional)

The fourth Home checkbox, Simulate activity & distance, controls whether QFit also writes a distance record and an exercise session into Health Connect when the run ends. It is on by default.
Whether this option is on or off, during a run QFit writes steps only. Only after the run ends (complete or cancel), if the option was checked for that run, QFit writes one distance + one exercise for the whole session based on your run settings (Walk → Walking; other intensities → Running).

For step-only games / apps (for example Pikmin Bloom), leave it off at first; turn it on only if step reading looks abnormal.
Or turn it on when you know the downstream app needs a workout / activity or distance (for example fitness apps that sync exercise sessions from Health Connect).
Changing the checkbox applies to the next run you start. In progress and History show On/Off for that run so you can confirm what was used.

6. Choose type and duration

  1. Type: defaults to Slow Jogging; you can also pick Walk, Jog, Marathon, or Sprint.
  2. Duration: drag the slider. For a first try, use 1–5 minutes (default is about 20).
  3. The estimate next to Duration shows roughly how many steps this run will write.

7. Tap Start and wait to finish

  1. When Health Connect is ready (and ideally Run notification + Battery Optimization), tap Start. The fourth checkbox is optional—see above.
  2. On the In progress screen, watch type, activity & distance On/Off, steps so far, and elapsed / total time.
  3. If Run notification is on, the status bar also shows the run.
  4. During the run, Health Connect receives steps as segments become due. Activity and distance (if enabled) appear when the run ends.
  5. The run ends when time is up. You can tap Cancel (with confirm): no further writes occur, but data already in Health Connect remains, and History shows Cancelled.
First run tip: try 1–3 minutes with the screen on and confirm steps increase. Then try screen-off or a longer duration.

8. Check History

  1. On Home, tap History at the bottom right.
  2. Each card shows start time, type, Activity & distance On/Off, duration, steps, and status (Completed / Cancelled).
  3. Tap the green underlined Details to expand segment write results (Room still stores per-segment distance for the log even if HC activity was off).
  4. Clear history only deletes local QFit records—not data already in Health Connect.

9. FAQ

Q. Health Connect stays unchecked?
Tap Health Connect again to finish granting access, and confirm Health Connect is installed.

Q. Battery Optimization stays unchecked?
Confirm you chose Unrestricted. QFit rechecks when you return; if needed, force-stop the app and reopen.

Q. Steps stop increasing with the screen off?
Keep Run notification and Battery Optimization on. After the screen turns on again, QFit tries to catch up writes that were due while the screen was off.

Q. Another app does not see the steps?
In Health Connect, give that app read access and confirm it can see data written by QFit.

Q. Should I turn on Simulate activity & distance?
For step-only games (e.g. Pikmin Bloom), leave it off first and turn it on only if steps look wrong. Turn it on when you know the downstream app needs a workout/activity or distance. Off still writes steps.

Q. What is the top-left menu?
About: purpose, disclaimer, and version numbers.
